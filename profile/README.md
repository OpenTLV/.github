# OpenTLV

OpenTLV is an open-source initiative for processing TLV (type-length-value) data.
Our goal is to build a maintainable ecosystem with clear documentation,
reproducible checks, and welcoming collaboration.

## Current status

The public repositories are being bootstrapped. Features, supported formats,
language integrations, and release guarantees will be documented in the relevant
project as they become available.

- [OpenTLV project](https://github.com/OpenTLV/opentlv)
- [Community policies and organization configuration](https://github.com/OpenTLV/.github)
- [Public repositories](https://github.com/orgs/OpenTLV/repositories?type=public)

## Get involved

Read our [contribution guidelines](https://github.com/OpenTLV/.github/blob/main/CONTRIBUTING.md)
and [code of conduct](https://github.com/OpenTLV/.github/blob/main/CODE_OF_CONDUCT.md).
Use the relevant project's issue tracker for proposals and reproducible bugs.

[security policy](https://github.com/OpenTLV/.github/blob/main/SECURITY.md).
