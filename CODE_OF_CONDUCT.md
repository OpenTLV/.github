# Code of conduct

OpenTLV welcomes participation regardless of background, identity, experience,
or ability. Be respectful, patient, and constructive. Critique ideas and code;
respect boundaries and accept good-faith feedback.

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing, and deliberate disruption are unacceptable. These expectations apply
in project issues, pull requests, discussions, and other project-managed spaces,
and when someone officially represents the project.

## Reporting and enforcement

Report abusive GitHub content using GitHub's Report content controls. For
project moderation, contact a repository maintainer through a contact method
they explicitly publish on their GitHub profile. If no private method is
available, ask for one without posting details or identifying affected people.
Do not use vulnerability reports for conduct complaints. If a maintainer is
involved, contact another uninvolved maintainer or GitHub Support.

Maintainers should handle reports discreetly, hear relevant context, and avoid
conflicts of interest. Confidentiality cannot be guaranteed beyond the people
and services required to investigate. Depending on severity and repetition,
maintainers may request corrections, remove content, or restrict participation
temporarily or permanently. Explain decisions privately where feasible. An
appeal may be requested from an uninvolved maintainer; if none is available,
GitHub's own reporting and appeal processes remain available.

This is an original project policy, not an adoption of a third-party code.
